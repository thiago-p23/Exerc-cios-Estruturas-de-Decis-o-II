# Cinco Números

Aplicação simples de console desenvolvida em Java para demonstrar o funcionamento de estruturas de repetição (`for`) por meio da impressão sequencial de cinco números.

## Funcionalidades

* **Contagem sequencial:** Exibe os números inteiros de `1` a `5` no console, um por linha.
* **Sintaxe simplificada:** Utiliza os recursos modernos do Java (*Compact Source Files* e `java.lang.IO`), dispensando a declaração explícita de classes e importações básicas.

## Pré-requisitos

* **Java Development Kit (JDK):** Versão 25 ou superior (ou JDK 21/23/24 com `--enable-preview` habilitado).

## Como Executar

1. Salve o código-fonte em um arquivo chamado `cinco_numeros.java`.
2. Abra o terminal na pasta onde o arquivo foi salvo.
3. Execute o arquivo diretamente (sem necessidade de compilação prévia):
   ```bash
   java cinco_numeros.java
